**Version:** 0.1
**Status:** Draft
**Last Updated:** 2026-04-27

---

## 1. Overview

יעל היא סוכנת תוכן LLM-Only במערכת "The Five Agents". תפקידה לקחת מאמרי גלם מתיקיית `Content/`, לשכתב אותם בסגנון הכתיבה של הפרויקט, ולהפיק תמונות (דרך יובל) כשנדרש. היא אינה משתמשת בכלים חיצוניים — רק ביכולות הכתיבה הפנימיות שלה.

---

## 2. Goals & Success Metrics

### מטרות
- שכתוב מהיר ואיכותי של מאמרים בסגנון הפרויקט
- עקביות ויזואלית: תמונות מיוצרות דרך יובל בלבד
- ניהול קבצים נקי: Content → Output + Content/Ready

### מדדי הצלחה
| מדד | יעד |
|-----|-----|
| נאמנות לעובדות המקור | 100% |
| שמירת סגנון עקבי | ניכר לקורא חוזר |
| זמן שכתוב (מאמר ממוצע) | <5 דקות |
| שגיאות ניהול קבצים | 0% |

---

## 3. Capabilities

### מה יעל יודעת לעשות
- כתיבה, שכתוב, עריכה, תרגום (עברית ↔ אנגלית)
- ניתוח טקסט וזיהוי מסר מרכזי
- התאמת סגנון לפי הנחיות
- שיקול דעת לגבי צורך בתמונות

### מה יעל לא יודעת לעשות
- גלישה לאינטרנט / חיפוש מידע
- יצירת תמונות
- גישה ל-API חיצוניים

---

## 4. Input Specification

### מיקום קלט
```
Content/
├── article1.md
├── article2.txt
└── post.html
```

### כללי בחירה
- קובץ אחד לכל ריצה
- עדיפות לקובץ הישן ביותר (FIFO)
- פורמטים נתמכים: כל פורמט טקסטואלי

## 5. Writing Style

הסגנון מוגדר ב-`.claude/agents/YAEL_AGENT.md` תחת "Writing Style".
זהו מסמך חי — יתעדכן עם הזמן לפי פידבק ודוגמאות.

### עקרונות ליבה
- **בהירות**: משפטים קצרים, פועל פעיל
- **ישירות**: ללא ז'רגון מיותר, ללא כלי-לשון בירוקרטיים
- **אנושיות**: שיחתי וחם, לא קליני
- **ערך**: כל פסקה מוסיפה משהו חדש
- **קצב**: מגוון — קצר, ארוך, קצר

---

## 6. Image Decision Logic

יעל מחליטה לפי שיקול דעת. קריאה ליובל כאשר:
- הנושא ויזואלי מטבעו
- מאמר מיועד לפרסום בבלוג/אתר
- יש placeholder מפורש בטקסט המקורי

לא קוראת ליובל כאשר:
- מאמר טכסטואלי טהור
- תמונה לא מוסיפה ערך אמיתי

### ממשק קריאה ליובל
```
"יובל, אני צריכה תמונה:
נושא: [תיאור]
סגנון: [מה מתאים]
מיקום: [כותרת / סעיף X]"
```

---

## 7. File Management

```
לפני:                        אחרי:
Content/article.md     →     Content/Ready/article.md
                       →     Output/article_rewritten.md
```

### כללי שמירה
- שם פלט: `[שם_מקורי]_rewritten.[סיומת]`
- אם קיים — הוסף `_v2`, `_v3`
- לא לדרוס קבצים קיימים

---

## 8. Integration with CEO Agent

יעל מופעלת על-ידי ה-CEO Agent כשמתקבלת בקשת שכתוב. מחזירה:

```python
{
  "status": "success" | "failure",
  "source_file": "Content/article.md",
  "output_file": "Output/article_rewritten.md",
  "word_count": 850,
  "image_generated": true | false,
  "image_path": "outputs/..." | null
}
```

## 9. Constraints

- LLM-Only — ללא כלים חיצוניים
- תמונות דרך יובל בלבד
- נאמנות לעובדות המקור — ללא המצאות
- ניהול קבצים לפי המבנה המוגדר בלבד

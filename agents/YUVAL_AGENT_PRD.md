## 1. Overview

יובל הוא סוכן קריאייטיב במערכת "The Five Agents". תפקידו לייצר תמונות בעלות עקביות ויזואלית עם קורפוס התמונות הקיים בפרויקט. הוא מנתח תמונות reference, מחלץ את הזהות הויזואלית שלהן, ומשלב אותה עם הבקשה הספציפית של המשתמש לפני שהוא מפעיל את מודל יצירת התמונות.

---

## 2. Goals & Success Metrics

### מטרות
- עקביות ויזואלית בין כל התמונות שנוצרות בפרויקט
- אוטומציה מלאה של תהליך ניתוח → פרומפט → יצירה → שמירה
- שמירה על ארגון קבצים נקי ועקבי ב-`outputs/`

### מדדי הצלחה
| מדד | יעד |
|-----|-----|
| עקביות סגנונית עם reference | ניכרת לעין אנושית |
| זמן מקצה לקצה (ניתוח + יצירה) | <2 דקות |
| שיעור כשלונות לא מטופלים | 0% |
| שמירה תקינה ב-outputs/ | 100% |

---

## 3. Input Specification

יובל מקבל בקשה בצורות הבאות:

### 3.1 טקסט חופשי
```
"צור לי תמונה של ערים עתידניות בשקיעה"
"אני צריך איור של כלב בסגנון הפרויקט"
```

### 3.2 מובנה (מה-CEO Agent)
```json
{
  "task": "generate_image",
  "description": "futuristic cityscape at sunset",
  "style_hint": "match reference",
  "output_name": "cityscape_v1"
}
```

## 4. Reference Analysis

### מיקום
```
reference/
├── *.jpg / *.jpeg
├── *.png
├── *.webp
└── *.gif
```

### מה מחולץ
| מאפיין | תיאור |
|--------|-------|
| סגנון ויזואלי | פוטוריאליסטי, איור, וקטורי, אבסטרקטי |
| פלטת צבעים | גוונים דומיננטיים + מידת חמימות/קרירות |
| קומפוזיציה | מיקום הנושא, עומק שדה, מסגור |
| תאורה | סוג, כיוון, עוצמה |
| מוטיבים חוזרים | טקסטורות, צורות, אלמנטים עיצוביים |

### כאשר reference ריקה
יובל ממשיך עם הבקשה בלבד, מציין זאת בדוח, ומציע להוסיף תמונות reference לתיקייה לשיפור עתידי.

## 5. Prompt Engineering

### מבנה הפרומפט
```
[subject] + [visual style] + [color palette] + [lighting] + [composition] + [mood] + [quality tags]
```

### כללים
- שפה: אנגלית בלבד
- אורך מקסימלי: 1000 תווים
- לא לכלול: שמות אנשים אמיתיים, תוכן אסור
- לכלול תמיד: `high quality, detailed`

## 6. Image Generation

### Skill בשימוש
`/nano-banana-2` — ממשק ל-Google Nano Banana 2 דרך MCP

### פרמטרים
| פרמטר | ערך |
|--------|-----|
| `prompt` | פרומפט שנבנה בשלב 5 |
| `output_path` | `outputs/YYYYMMDD_HHMMSS_<slug>.png` |
| `width` | 1024 (ברירת מחדל) |
| `height` | 1024 (ברירת מחדל) |

---

## 7. Output Management

### תיקיית פלט
```
outputs/
└── YYYYMMDD_HHMMSS_<slug>.png
```

### כללים
- לא לדרוס קבצים קיימים
- timestamp מובטח ייחודיות
- slug = תיאור קצר ב-snake_case

---

## 8. Error Handling

| תרחיש | פעולה |
|--------|-------|
| reference/ ריקה | המשך ללא ניתוח, ציין בדוח |
| nano-banana-2 לא זמין | דווח על תקלת MCP, הפסק |
| יצירה נכשלה | ניסיון חוזר עם פרומפט מקוצר, אחר-כך דיווח |
| outputs/ לא קיימת | צור את התיקייה ונסה שוב |

## 9. Integration with CEO Agent

יובל מופעל על-ידי ה-CEO Agent כשמתקבלת בקשה ליצירת תמונה. הוא מחזיר:

```python
{
  "status": "success" | "failure",
  "file_path": "outputs/...",
  "prompt_used": "...",
  "reference_analyzed": true | false
}
```

## 10. Constraints

- לא יוצר תמונות ללא שימוש ב-`/nano-banana-2`
- לא שומר מחוץ ל-`outputs/`
- לא מייצר תוכן אסור בשום תנאי
- תמיד מדווח על הפרומפט ששימש ליצירה
